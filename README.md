# THE SNAIL PARADOX

A standalone Canvas platformer made with vanilla JavaScript. No dependencies, build tools, or external assets.

## Play
Open [the game](index.html) in a modern desktop browser, then click **ENTER THE RUINS**.

## Controls
- **A/D** or **←/→** — move
- **Space / W / ↑** — jump
- **Shift** — dash
- **S / Ctrl** — slide under the low tunnel
- **Hold R** — rewind the last three seconds of player movement
- **E** — short-range teleport
- **Q** — ground slam while airborne; hit the ancient seal to open the gate
- **Esc** — pause/resume

Avoid spikes, use the checkpoint, activate the seal, and reach the glowing portal. The immortal snail pursues the player and remembers the route.

## Deploy
The included GitHub Actions workflow publishes the repository root to GitHub Pages on pushes to `main`. In repository **Settings → Pages**, set **Source** to **GitHub Actions** if it is not already selected.
